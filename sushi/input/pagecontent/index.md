### Introduction

This implementation guide provides maps to transform documents from DASTA to FHIR and back using the [FHIR Mapping Language (FML)](https://www.hl7.org/fhir/mapping-language.html).

### Maps

The maps listed in the table below are available as [FHIR Structure Maps](https://www.hl7.org/fhir/structuremap.html).
